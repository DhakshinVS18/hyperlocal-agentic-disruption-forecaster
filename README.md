# Hyperlocal Agentic Disruption Forecaster

An autonomous AI agent that predicts delivery delays in Chennai quick-commerce zones (rain, traffic, high orders) and recommends actions (reroute riders, move inventory).

## Tech Stack (MVP)
- Forecasting: XGBoost / Prophet
- Agent: LangChain + Phi-3-mini
- Dashboard: Streamlit
- Data: Synthetic + Chennai weather mock
